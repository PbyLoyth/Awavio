# Changelog

## 0.1.0 — 2026-10-12

First public Awavio release for Windows x64.

### Added

- A colorful radiant-eye identity, a redesigned duration window and a floating countdown widget.
- Duration presets alongside days, hours and minutes input.
- Timed keep-awake sessions using the Windows execution-state API.
- Optional closed-lid operation through temporary plugged-in and battery lid-action changes.
- Restoration of original lid actions while preserving values changed by the user.
- Recovery journal and a per-user recovery task for interrupted sessions.
- Display-on toggle, battery cutoff, remembered widget position and optional startup at sign-in.
- Self-contained Windows x64 release ZIP with installation and removal tools.
- English and Turkish documentation with native application previews.
- Core tests, Windows build workflow and a native power-validation harness.

See [VALIDATION.md](VALIDATION.md) for verification results and the remaining hardware test boundaries.
